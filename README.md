## Project Description
A Python-based Smart Campus Booking System that allows students to book campus facilities like study rooms and labs. Developed as part of Programming 512.

## Files Included
- `main.py` - Main entry point
- `gui.py` - Graphical User Interface  
- `campus.py` - Campus logic
- `database.py` - Database handling
- `users.py` - User management
- `utils.py` - Helper functions

## Technologies Used
- Python 3
- Tkinter GUI
- SQLite Database
